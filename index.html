故事主线 第一层 · 产业逻辑
假设你要给一座城市建一个「最强大脑」——智算中心，让它跑大模型、做 AI 推理。你需要什么？
一座智算中心，本质上就是一个「能算、能记、能联网」的 AI 系统。下面六道工序，对应你关心的所有板块——它们不是并列的零件，而是从地基到大脑的建造顺序。
六道工序 故事 → 真实板块
每一道工序 = 一个比喻 + 对应的真实板块。颜色区分四大功能域：算+记 / 造 / 装+连 / 传 / 当家。

① 地基和房间 → PCB

当家 · 承载与互联
绿色电路板上刻满铜做的「马路」，所有零件焊在上面，靠这些马路通电、传信号。没有 PCB，芯片没地方住，也没法彼此通话。覆铜板是 PCB 的核心基材（占成本 30–40%），MLCC 这类被动元件则是焊满板子的"电子大米"——两者都随 AI 服务器高多层板放量。
PCB 印制电路板

② 大脑与记忆 → 芯片 / 存储 / 半导体

算 + 记 · 核心成品
半导体是「材料」，芯片是「成品」，存储是「管记忆的那一类芯片」。包含关系：半导体 ⊃ 芯片 ⊃ 存储。GPU/NPU 是大脑，DRAM/NAND/HBM 是记忆。算力租赁运营商是「把大脑出租」的服务层。
半导体芯片存储算力租赁

③ 造芯片的工厂 → 半设 / 半材

造 · 上游供给
半设是巨型机器（光刻/刻蚀/沉积），能用很多年、慢慢折旧——损耗小、是固定资产。半材是硅片/光刻胶/特气/靶材，每做一批就吃掉一批，得不停补货。
半设 半导体设备半材 半导体材料

④ 总装车间 → 先进封装

装 + 连 · 集成
裸芯片是块脆硅（die），封装厂把它包起来、引出脚、还能叠起来。HBM = 多层 DRAM 叠起 + 硅通孔连接 = 存储 + 封装的合体；Chiplet 把多块芯片拼一包。
先进封装HBMChiplet

⑤ 联网开会 → 交换机 / 光模块 / 光纤

传 · 光通信
电信号在铜线跑远了会衰减，于是改用光传。光纤是玻璃高速公路，光模块是路口「翻译官」（电↔光），交换机是「总调度台」——决定数据发给哪块 GPU/服务器。CPO 把光引擎和交换机芯片共封装。
交换机光模块光纤

⑥ 下一步进化 → CPO

装 + 连 · 融合
普通光模块是「插在板边的独立盒子」。CPO 更激进：把光引擎和交换机/计算芯片封装在同一基板、紧挨着。距离更短→更省电、更低延迟。CPO = 光模块升级 + 先进封装应用，故并入板块④⑤。
CPO 共封装光学

与硬件的关系：半导体故事线 = 盖好"AI 大脑工厂"（算力 / 存储 / 网络）；AI 应用 = 让这个大脑去干活、产出服务与收入。硬件是"卖铲人"（确定性高、机构重仓），软件是"淘金者"（弹性大、主题驱动、业绩兑现慢）。传导：应用爆发 → 算力需求 → 硬件扩产（下游拉动上游）；硬件降价普及 → 降低应用门槛（上游反哺下游）。节奏：硬件先涨（算力基建确定性），应用后涨（业绩兑现 / AI 落地），是科技进攻主线的下游延伸 / 价值实现层。
攻守转换：逆指数防御板块 防守后盾 · 个股穷举
科技（半导体 / 存储 / CPO）不会一直涨，回落时 A 股有几类板块承担"稳住指数"职责。它们分两种机制：主动护盘（银行保险）与逆指数避险（电力煤炭等高股息）。下方为要点 + 个股穷举；完整独立页见 攻守转换-逆指数防御板块.html。
类型代表板块谁在买什么时候动本质
A类 · 主动护盘银行、保险国家队 / 主力指数快速破位、恐慌踩踏拉权重股硬托沪指重心

一句话：银行保险是"主动拉"，电力煤炭是"被动涨"。科技一回调，避险资金涌入、权重又不小，就把指数托住了。
误区修正：证券 ≠ 默认护盘工具。 券商是顺周期品种（赚成交量、自营、两融），科技退潮时资金反而减券商，不防御；公募低配、散户套牢盘重，硬拉成本高。护盘优先顺序：银行、保险 > 券商。券商只在"指数急跌破位 + 资本市场改革预期"时脉冲，是反弹进攻旗手，不是防御底仓。

投资要点 我的分析
从「政策→基建→板块→个股」四层传导里，提炼确定性、外部变量与节奏风险。

确定性排序（从政策到业绩的传导强度）

设备材料 / PCB最确定·扩产配套
光模块 / 光纤确定+出海
存储 / 先进封装高弹性·周期
交换机 / 算力租赁订单/主题驱动
国产 AI 芯片预期差最大
  • 券商共识「四大高确定性环节」：PCB、液冷、光模块、HVDC
  • 新增变量：Agentic AI（OpenClaw）使 Token 消耗 7 倍级增长，CPU:GPU 配比向 1:1 回归 → 利好内存接口（澜起）与通用算力
  • 交换机/算力租赁是主题弹性：前者卡超节点互联、后者卡算力缺口，业绩兑现节奏快但波动大

外部变量（决定链路的「松紧」）

  • BIS 出口管制：卡高端 GPU/设备/EDA → 收紧时国产替代情绪升温，但高端供给受限
  • 英伟达对华摇摆：H20 禁了又放、B30 新特供；放开→云厂真有卡用→基建订单落地；收紧→国产 GPU 预期升温
  • FCC：管通信/认证，主要影响光模块/光纤/交换机出口准入与检测认证
  • 核心公式：硬科技股价 = 国产替代情绪(看管制) + 全球真实需求(看英伟达/云厂 capex)

风险与节奏

  • 周期不消失：存储强周期，机构预测供给释放拐点约在 2028 年，此前价格高位震荡
  • 传导时滞：政策→基建(快)→板块订单(1-2 年)→业绩(滞后)；股价常提前透支预期
  • 估值透支：2026 上半年电子指数 +66%、半导体 +73%、元器件 +115%，需警惕预期抢跑
  • 算力租赁需警惕「框架订单≠确定性收入」、设备交付与客户验收节奏（如行云科技 154 亿长单仍需兑现）
  • 地缘冲突、国产替代不及预期、研发失败均为显性风险
